# 8085 Microprocessor Simulator

A Java-based 8085 microprocessor simulator designed to help students understand assembly language execution and fundamental computer architecture concepts through an interactive graphical interface.

## Overview

Understanding how assembly instructions affect CPU registers and memory can be challenging when learning microprocessor architecture. This project provides a simulator for exploring instruction execution and observing changes in the simulated processor state.

## Features

- **Assembly Code Input:** Provides an interface for entering and working with assembly code.
- **Instruction Execution:** Simulates assembly instruction execution within the supported instruction set.
- **Register Visualization:** Displays simulated register values during program execution.
- **Memory Visualization:** Provides a view of the simulator's memory state.
- **Execution State Management:** Maintains the simulated processor state as instructions are processed.
- **Code Persistence:** Includes support for saving code and maintaining code-related data, as implemented in the project.
- **Graphical User Interface:** Uses Java GUI components to provide an interactive simulator interface.

## Tech Stack

- **Programming Language:** Java
- **User Interface:** Java GUI components
- **Core Concepts:** Assembly language, microprocessor architecture, registers, memory management, instruction execution

## How It Works

1. Enter assembly code using the simulator interface.
2. Execute supported instructions through the simulator.
3. Observe changes in the simulated registers and memory.
4. Examine the processor state to understand the effects of instruction execution.

## Learning Objectives

- Understand the fundamentals of the 8085 microprocessor.
- Explore the relationship between assembly instructions, registers, and memory.
- Learn how processor state changes during program execution.
- Gain practical experience with Java GUI development and simulation logic.
